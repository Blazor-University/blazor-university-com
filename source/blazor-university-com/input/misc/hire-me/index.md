I am Peter Morris, a senior C# and .NET contractor with over 30 years of commercial experience. I help
organisations build new C#/Blazor applications, modernise ageing code bases, and get the most out of the .NET platform.
If you are reading this site, you already know that I am the author of Blazor-University.

## Why hire me?

I am recognised as a leading authority on Blazor. I was an early adopter of the platform, I run the definitive free
learning resource in Blazor-University, and I have built open-source libraries, including Fluxor for state management
and BlazorValidation, that developers around the world rely on every day. When you hire me, you are not hiring
someone who has read about Blazor, you are hiring someone who has shaped how other developers learn it.

That depth of knowledge matters in production. I have delivered systems that handle hundreds of thousands of requests
per day, systems accountable for billions of pounds of investment transactions, and regulated systems in government,
insurance, utilities, and logistics across the UK and the United States.

## What I can do for you?

### Blazor and modern .NET development

I build production-quality applications in every hosting model Blazor offers: Interactive Server, Interactive WebAssembly,
Interactive Auto, Static Server Rendering, and Blazor Hybrid. I combine that with clean ASP.NET Core APIs,
Entity Framework Core, and SQL Server or CosmosDB.

### Architecture and cloud

I design distributed, event-driven systems on Azure using Functions, Service Bus, and related services. I apply
Domain-Driven Design and SOLID principles to keep systems maintainable as they grow, and I bring the discipline of
test-driven development to every engagement.

### Leading and levelling up teams

I do not just write code. I review architectures, recommend changes, and mentor other developers. I have guided teams
building their first Blazor application from scratch, restructured single-user client code into multi-user server code,
and introduced TDD and dependency injection to teams who had never used them before.

## The outcome

The work I am most proud of is not measured in features. It is measured in what it unlocks. I have helped reduce an
energy provider switching process from three weeks to 24 hours to meet new government guidelines, helped build
a site capable of handling around 800,000 searches on a peak day, and taught junior developers the enterprise
techniques that prepare them for senior roles.

I aim to leave every team I work with more capable than I found it.

## Availability

I am currently available for contract work and consulting. I prefer remote engagements, but I am willing to travel within
about 30 miles of Tamworth when a project needs it, or further if the frequency of travel is low.

<script>
   (function () {
      const carousel = document.querySelector("[data-testimonial-carousel]");
      if (!carousel) {
         return;
      }

      const track = carousel.querySelector("[data-testimonial-track]");
      const slides = Array.from(carousel.querySelectorAll("[data-testimonial-slide]"));
      const dotsContainer = carousel.querySelector("[data-testimonial-dots]");
      const prevButton = carousel.querySelector("[data-testimonial-prev]");
      const nextButton = carousel.querySelector("[data-testimonial-next]");

      let currentIndex = 0;
      let timer = null;
       const intervalMs = 15000;

      const goTo = (index) => {
         currentIndex = (index + slides.length) % slides.length;
         track.style.transform = "translateX(-" + currentIndex * 100 + "%)";
         Array.from(dotsContainer.children).forEach((dot, i) => {
            dot.classList.toggle("is-active", i === currentIndex);
         });
      };

      const startTimer = () => {
         stopTimer();
         timer = window.setInterval(() => goTo(currentIndex + 1), intervalMs);
      };

      const stopTimer = () => {
         if (timer) {
            window.clearInterval(timer);
            timer = null;
         }
      };

      prevButton.addEventListener("click", () => {
         goTo(currentIndex - 1);
         startTimer();
      });

      nextButton.addEventListener("click", () => {
         goTo(currentIndex + 1);
         startTimer();
      });

      dotsContainer.addEventListener("click", (event) => {
         const dot = event.target.closest("[data-testimonial-dot]");
         if (!dot) {
            return;
         }
         goTo(Number(dot.dataset.index));
         startTimer();
      });

      carousel.addEventListener("mouseenter", stopTimer);
      carousel.addEventListener("mouseleave", startTimer);

      prevButton.addEventListener("mouseenter", stopTimer);
      prevButton.addEventListener("mouseleave", startTimer);
      nextButton.addEventListener("mouseenter", stopTimer);
      nextButton.addEventListener("mouseleave", startTimer);

      slides.forEach((slide, index) => {
         const button = document.createElement("button");
         button.type = "button";
         button.dataset.index = index;
         button.dataset.testimonialDot = "";
         button.setAttribute("aria-label", "Go to testimonial " + (index + 1));
         button.className = "t-dot";
         dotsContainer.appendChild(button);
      });

      goTo(0);
      startTimer();
   })();
</script>
