Welcome to Blazor University. This section introduces Blazor and provides the foundational knowledge you need to start building applications.

## Prerequisites

You should be comfortable with C#, HTML, and basic web development concepts. The examples in this site target .NET 10 and use the Blazor Web App template.

## What is covered in this section

1. [What is Blazor?](/overview/what-is-blazor/) - An introduction to the Blazor framework.
2. [What is WebAssembly?](/overview/what-is-webassembly/) - Understanding the technology that enables client-side Blazor.
3. [Blazor hosting models](/overview/blazor-hosting-models/) - The different render modes available.
4. [Installing Blazor](/overview/installing-blazor/) - Getting the tools you need.
5. [Creating a new project](/overview/creating-a-new-project/) - Your first Blazor Web App.
6. [Creating a page](/overview/creating-a-page/) - Building your first component.
